# .clang-tidy suppressions and notes

This file records clang-tidy warnings we intentionally suppressed or deferred during
the limited, safe auto-fix pass applied on branch `code-quality/auto-fixes`.

Summary of suppressed checks and rationale
- modernize-use-nullptr: suppressed in a few vendor/compatibility shims where `NULL` is
  used for C compatibility and changing it risks behavioural differences.
- readability-const-return-type: suppressed in generated files where signatures are
  maintained for ABI compatibility.
- bugprone-macro-parentheses: suppressed for third-party macro wrappers we don't maintain.

Files / locations (representative)
- deps/ (third-party sources and vendored compatibility shims)
- scripts/ (build helper scripts where clang-tidy reports are noisy)

Notes
- This suppression file documents why certain clang-tidy findings were not auto-fixed.
  It is intentionally conservative; we prefer to leave larger refactors or ABI-sensitive
  changes for a dedicated follow-up review.

If you want a stricter pass, run clang-tidy on the project and expand this file with
explicit !-style entries per-file to document each suppressed diagnostic.
